# Проектирование информационной системы управления сетью кофеен

**Роль:** Системный / Бизнес-аналитик  
**Тип проекта:** Командный проект  

---

## 📌 Задача
Спроектировать сквозную архитектуру сервиса автоматизации операционных процессов сети кофеен (найм, учет смен, кассовый учет, система геймификации и мотивации персонала).

---

## 🛠 Что сделано
* **Анализ бизнес-процессов:** разработал бизнес-модель (Business Model Canvas TO-BE), карту процессов и User Story Mapping для ролей: Бариста, Менеджер, Бухгалтер.
* **Архитектурное проектирование:** спроектировал системный ландшафт и архитектурные схемы C4 (Context L1, Container L2) для распределенной системы (Web App, POS-терминалы, Telegram-бот, Backend API).
* **Интеграционные решения:** описал схемы интеграции компонентов:
  * Синхронизацию чеков кассового модуля через WebSocket;
  * Авторизацию с ролевой моделью доступа (RBAC);
  * Модуль парсинга откликов.
* **UML-моделирование:** спроектировал Sequence-диаграммы сценариев авторизации менеджера, утверждения расписания и рассылки уведомлений сотрудникам.
* **Спецификация сервисов:** разработал спецификацию и архитектуру сервиса Telegram-бота (Python/aiogram, кэширование состояний, обработка Webhook-событий бэкенда).

---

## 🎯 Результат
Сформировал полный пакет архитектурной документации и диаграмм (C4, Sequence, Story Map), обеспечив прозрачную декомпозицию задач для команды разработки.

---

## 🧰 Стек и инструменты
* **Моделирование и схемы:** C4 Model, UML (Sequence), BPMN, Draw.io
* **Методологии и анализ:** User Story Mapping, Business Model Canvas, Role-Based Access Control (RBAC)
* **Протоколы и API:** REST API, WebSocket, Webhooks
* **Технологии реализации сервиса бота:** Python (aiogram)
